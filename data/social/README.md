# 天下りマップ 投稿キュー

`content-queue.csv` は Google スプレッドシートへそのままインポートできる投稿候補です。毎朝のAI編集タスクが内容を確認したうえで `content-queue.json` に高品質な原稿を 1 件だけ追加し、`npm run sync:social-queue` がCSVへ反映します。

- X は 2 投稿のスレッドです。1投稿目はネットミーム調で資料の要点を読ませ、返信は天下りマップへの導線です。
- すべて `要確認` の下書きです。X や note へ自動送信はしません。
- note 下書きは、一次資料1件の情報を言い換えただけにしません。法人公式・所管情報など追加の一次資料で背景を補えない場合は、note原稿を作らず見送ります。
- 人物・法人について、違法性、不正、癒着、採用の経緯を断定する文章は生成しません。
