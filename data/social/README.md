# 天下りマップ 投稿キュー

`content-queue.csv` は Google スプレッドシートへそのままインポートできる投稿候補です。毎朝の低リスクなデータ公開が成功したときだけ、同じ一次資料に基づく候補を 1 件追加します。

- X は 2 投稿のスレッドです。1投稿目は資料の要点、返信は天下りマップと一次資料への導線です。
- すべて `要確認` の下書きです。X や note へ自動送信はしません。
- note 下書きは一次資料 1 件だけでは公開不可です。法人公式・所管情報など追加の一次資料で背景を補える場合のみ公開します。
- 人物・法人について、違法性、不正、癒着、採用の経緯を断定する文章は生成しません。
