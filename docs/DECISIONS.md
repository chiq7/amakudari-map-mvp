# 天下りマップの編集方針

## 読者向け画面では守り文を出さない

- 記事・一覧・詳細・カード・フッターに、掲載基準、出典、公開元、確認日、資料だけでは確認できないこと、一般的な注意書き、免責、評価しない旨を定型で表示しない。
- 記事末尾に出典一覧を置かない。法人公式ページなど、読者の次の行動に役立つリンクだけを表示する。
- 根拠URL、確認日、調査メモは編集用データに保持し、公開画面には出さない。
- 読者に誤解を与えるおそれがある場合も、一般的な注意書きではなく、その場で必要な具体的事実だけを短く書く。
- 公開ページは、人物の移動、法人の業務、制度上の接点、時系列、比較という答えを最初に見せる。
