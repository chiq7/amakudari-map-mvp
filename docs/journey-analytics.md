# トップ・資料リンクの計測

既存のタグからイベント名で分類する。GA4のカスタムディメンション登録・キーイベント設定は不要。公開後、既存の週次GA4イベント集計（`eventName` × `eventCount`）で確認する。

| イベント名 | 対象 |
| --- | --- |
| `click_home_definition` | トップ「天下りとは？」の「再就職等規制と公表制度を読む」（`/about#reemployment-rules`） |
| `click_home_ministry_list` | 同じ案内枠の「省庁別一覧」（`/ministries`） |
| `click_home_company_list` | 同じ案内枠の「企業・法人一覧」 |
| `click_public_source_doc` | データ案内内の公的機関資料リンク、法人詳細で公的資料と明示されたリンク |
| `click_company_official_site` | 法人詳細で「法人公式」と明示されたリンク |

ヘッダー・注目枠のリンク、人物ページ、登記・gBizINFO等の照会、その他の外部リンクは新分類の対象外。既存の `click_internal_link` と `click_source_link` は従来どおり発火するため、新旧の件数は合算しない。新イベントの送信パラメータにリンク先URL、ページの検索クエリ、入力値は含めない。

公開後の確認順は、対象リンクが従来どおり開くこと、各クリックで該当イベント名が1回だけブラウザから送出されること、GA4で対象イベントが受信・集計されること。テスト操作と実利用を混ぜず、測定開始日より前に数値をさかのぼらない。イベント件数は利用人数・資料到達率・読了を示さない。率を出す場合は別途、対象入口セッションを分母に、同じ条件でクリックがあった一意セッションを集計できるかを検証する。
