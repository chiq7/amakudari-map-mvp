# 天下りマップ 実装前チェック・修正メモ

## 基本方針

Stitchから取得したHTMLは、実装の完成コードではなく、構造・文言・配置の参考資料として扱う。

実装時は、Stitch上の最新版フレームの見た目を正とする。
HTMLは参考にするが、HTML内にあるStitch由来の不具合・文字化け・重複・不要なstyle・class重複は修正する。

## 対象ページ

MVPで実装するページは以下の6ページ。

* TOPページ
* ランキングページ
* 法人検索 / 法人一覧ページ
* 法人詳細ページ
* 個人詳細ページ
* データ方針ページ

## 実装URL

* `/`：TOPページ
* `/rankings`：ランキングページ
* `/corporations`：法人検索 / 法人一覧ページ
* `/corporations/[slug]`：法人詳細ページ
* `/persons/[slug]`：個人詳細ページ
* `/data-policy`：データ方針ページ

## 共通UI方針

* 文言は中立にする
* 直接的な煽り文言は使わない
* 「怪しい」「疑惑」「癒着」「問題あり」「要注意」「黒幕」「闇」「告発」「暴露」「晒し」は使わない
* 特定の個人・法人・省庁の不適切性を断定しない
* 赤系・警告色は基本使わない
* 色は白、薄グレー、ネイビー、淡いブルーを基本にする
* 重要な数字はカード、太字、バッジ、淡い青背景などで分かりやすく見せる
* 文言で煽らず、数字とUIで気づかせる
* スクショされたときに、1枚で何のページか・どの数字が重要か伝わるようにする

## 共通コンポーネント化するもの

* Header

* SearchBox

* HighlightStatCard

* RankingCard
* DataNotice / DisclaimerBox
* Breadcrumb

## 共通Header方針

Headerは全ページで統一する。

* 左：天下りマップ ロゴ
* ナビ：

  * 話題から探す
  * ランキング
  * 法人検索
  * データ方針
* 右：検索ボックス
* 白背景 + 薄い下線
* 高さは56〜64px程度
* TOP HTMLのようにヘッダーが大きくなりすぎないようにする
* 不要なpersonアイコンは、ログイン機能がないなら削除する
* 各ページで正しいナビをアクティブ表示にする

## Headerアクティブ表示

* `/`：アクティブなし、またはロゴのみ
* `/rankings`：ランキング
* `/corporations`：法人検索
* `/corporations/[slug]`：法人検索
* `/persons/[slug]`：法人検索
* `/data-policy`：データ方針

法人詳細ページでは、Stitch上で一時的に「データ方針」がアクティブになるズレがあったため、実装時は必ず「法人検索」をアクティブにする。

## フォント方針

HTMLによって `Plus Jakarta Sans` のみになっているページがあるが、日本語サイトなので実装時は以下を基本にする。

```css
font-family: "Noto Sans JP", "Plus Jakarta Sans", sans-serif;
```

## Stitch由来の共通修正

HTMLをそのまま貼り付けない。以下を必ず確認して修正する。

* 日本語文字化け
* 誤字
* 重複セクション
* 不要な `opacity: 0`
* 不要な `style=""`
* Tailwind classの重複
* `text-[28px] text-[32px]` のような競合class
* `href="#"` のままのリンク
* 不要なpersonアイコン
* 英語表記残り
* ページごとのHeader差分
* スマホ表示崩れ
* テーブル横スクロールの有無

## TOPページ 修正メモ

TOPページHTMLは採用。
ただし実装時に以下を修正する。

* Headerが大きすぎるため、共通Headerに合わせて調整
* `py-8` のような大きすぎる余白は圧縮
* ロゴサイズの重複classを整理
* ナビ文字サイズの重複classを整理
* フォントはNoto Sans JP優先
* Footerの `All rights reserved.` は必要なら削除し、国内向けに寄せる
* すべての `href="#"` を導線仕様に置き換える

TOPで維持する要素：

* ヒーロー
* メイン検索
* 主要統計カード

  * 公表再就職情報
  * 受け入れ法人
  * 退職翌日再就職
  * 30日以内再就職
* 人気の切り口
* 注目の公表情報
* ランキングから探す
* 法人名から探す
* 集計データから探す
* データ方針への導線

## ランキングページ 修正メモ

ランキングページHTMLは採用。

維持する要素：

* ページタイトル「ランキングから探す」
* 中立注記
* 絞り込み
* 4つのランキング

  * 公表再就職者数
  * 退職翌日再就職件数
  * 30日以内再就職件数
  * 平均待機日数
* 関連する切り口から探す

実装時の注意：

* 退職翌日再就職件数ランキングは淡い青背景や青系アクセントで目立たせる
* 上部のフィルター・タブ周りは縦に間延びしないようにする
* ランキング本体がファーストビューで見えやすいようにする
* 数字の単位は「人」「件」「日」を正しく使い分ける
* 「もっと見る」「詳細ランキングを見る」などの文言は統一する

## 法人検索 / 法人一覧ページ 修正メモ

法人検索ページHTMLは採用。

維持する要素：

* ページタイトル「法人検索」
* 検索フォーム
* 省庁・法人種別・地域フィルター
* 退職翌日再就職あり
* 30日以内再就職あり
* サマリーカード
* 法人一覧テーブル
* 関連する切り口から探す
* データ方針への導線

実装時の注意：

* 検索ボタンが強すぎる場合は、全体トンマナに合わせる
* テーブルはスマホで横スクロール可能にする
* 法人名・数字・タグが小さくなりすぎないようにする
* 「退職翌日再就職あり」「30日以内再就職あり」は淡い青系で分かりやすくする

## 法人詳細ページ 修正メモ

法人詳細ページHTMLは採用。

維持する要素：

* パンくず
* 法人名
* サブタイトル
* 省庁タグ
* 主要統計カード

  * 公表再就職者数
  * 最多出身省庁
  * 平均待機日数
  * 退職翌日再就職
* 中立注記
* 公表再就職者一覧テーブル
* 元省庁の内訳
* 待機日数の分布
* 関連情報
* 出典リンク

実装時の注意：

* Headerのアクティブは「法人検索」
* 氏名をテーブルの左端にしない
* テーブル順は以下を基本にする
  元省庁 → 離職時官職 → 氏名 → 再就職先での地位 → 離職日 → 再就職日 → 待機日数 → 出典
* 待機日数0日は淡い青系バッジで表示
* 赤系・警告色は使わない
* 出典リンクは必ず残す

## 個人詳細ページ 修正メモ

個人詳細ページHTMLは採用。

維持する要素：

* パンくず
* H1「〇〇 氏の公表再就職情報」
* サブタイトル「政府・各省庁等の公表資料に基づく再就職情報」
* サマリーカード

  * 元省庁
  * 離職時官職
  * 再就職先
  * 待機日数
* 再就職プロフィール・フロー
* タグ
* 出典・公表資料
* 免責注記
* 関連リンク

実装時の注意：

* 個人ページは最も慎重にする
* 顔写真は入れない
* SNSリンクは入れない
* 長い略歴は入れない
* 本人評価は入れない
* 噂・推測は入れない
* 「天下り」タグは個人詳細ページでは使わない
* タグは「再就職情報」など中立的な表現にする
* 待機日数0日は淡い青系で静かに目立たせる
* 赤系・警告感・晒し感を出さない

## データ方針ページ 修正メモ

データ方針ページHTMLは採用。
ただし、実装時に必ず修正する。

維持する要素：

* H1「データ方針」
* H1直下の説明文
* 上部3カード

  * 公表資料に基づく整理
  * 中立的なデータ表示
  * 出典リンクの明示
* データソース
* 表示項目と抽出ルール
* 待機期間の算出について
* タグ付け・ランキング・集計
* 免責事項・法的判断について
* 掲載内容の修正・お問い合わせ
* 下部導線

必ず修正する項目：

* 下部に重複している3カードがある場合は削除
* 下部導線は以下にする

  * 法人検索へ
  * ランキングを見る
  * TOPへ戻る
* 誤字修正

  * `離職時儰職` → `離職時官職`
  * `離職時点の儰職` → `離職時点の官職`
  * `名誉毉損` → `名誉毀損`
* 免責見出しに `opacity: 0` がある場合は削除し、表示する
* フッターの英語表記は必要に応じて日本語寄せする

データ方針ページは、サイト全体の信頼性を支えるページ。
告発・批判・断定ではなく、公表資料を整理している中立的なデータベースであることが伝わるようにする。

## Footer方針

Footerは全ページで統一する。

* 天下りマップ
* 免責事項
* プライバシーポリシー
* データ方針
* お問い合わせ

英語表記は最小限にする。
`All rights reserved.` は残しても致命的ではないが、国内向けの一貫性を重視するなら削除または日本語寄せする。

## 実装後チェック

実装後に必ず確認する。

* 全ページのHeaderが統一されているか
* アクティブナビが正しいか
* Footerが統一されているか
* `href="#"` が残っていないか
* 日本語文字化けがないか
* `opacity: 0` が残っていないか
* 重複セクションがないか
* 赤系・警告色が使われていないか
* 個人ページが晒し感・告発感になっていないか
* スマホ表示で崩れていないか
* テーブルが横スクロールできるか
* 出典リンク・データ方針導線が残っているか
