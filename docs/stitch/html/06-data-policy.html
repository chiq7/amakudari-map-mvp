データ方針

本サイトは、政府・各省庁等が公表している再就職関連資料をもとに、検索・閲覧しやすく整理したデータベースです。掲載情報について、当サイトが個人・法人・省庁の不適切性を独自に判断するものではありません。

analytics

公表資料に基づく整理

内閣官房や各省庁が公表する一次資料を基に、情報を機械的に整理・掲載しています。

balance

中立的なデータ表示

特定の意図や主観を排除し、事実に基づいたデータ検索・閲覧機能を提供します。

link

出典リンクの明示

各データには出典となる公表資料へのリンクを明示し、透明性を確保しています。

source データソース（出典元）

  • 内閣官房 国家公務員の再就職状況の公表資料
  • 各省庁（外務省、財務省等） 各省庁における再就職情報の公表資料
  • 総務省 地方独立行政法人及び特殊法人の役員人事情報
  • 国立国会図書館 政治・行政関連アーカイブ（WARP）
info

当サイトは機械的なプログラムによってデータを収集・整理しているため、表記の揺れや、一次資料自体の誤りにより実際の事実と異なる場合があります。最新かつ正確な情報は必ず各省庁の公式サイトをご確認ください。

schedule 「待機期間」の算出について

当サイトでは、「離職日」から「再就職日」までの日数を「待機期間」として算出しています。

0日 / 30日未満

離職後すぐに再就職したケースを視覚的に区別するためにハイライト表示を行う場合があります。これは統計的な比較を容易にするためのものであり、不適切な再就職であることを示唆するものではありません。

例外の考慮

出向や定年退職、自己都合退職などの区分は一次資料に準拠しますが、システム上すべての個別事情を網羅できない場合があります。

label タグ付け・ランキング・集計

膨大な公表資料の中からユーザーが必要な情報にたどり着きやすくするため、以下の加工を行っています。

  • 業種カテゴリ: 法人種別（独法、公益、民間等）によるタグ付け
  • 省庁別集計: 省庁ごとの再就職人数の推移の可視化
  • ランキング: 検索頻度や再就職人数等に基づく並び替え（批判や推奨を目的としません）
gavel

免責事項・法的判断について

本サイトは、公表資料に基づく再就職情報を検索・閲覧しやすく整理したデータベースです。掲載されている再就職事例について、倫理的な妥当性、法的整合性、または不祥事の有無について当サイトが独自の判断を下すことはありません。特定の人物や団体への誹謗中傷、名誉毉損に繋がるような情報の利用は固く禁じております。データに基づかない主観的な批判は行もないよう、利用者の皆様には冷静かつ客観的な情報活用をお願い申し上げます。

掲載内容の修正・お問い合わせ

事実と異なるデータが表示されている場合や、情報の削除依頼等は、一次資料のURLを添えて下記よりご連絡ください。
確認後、順次対応いたします。
